# ADR 001 – Navigation Strategy
Status: Accepted

## Context
Ink & Insight uses a soft dark-academia aesthetic. Styling must be theme-driven and flexible.

## Decision
Use customer styling with StyleSheet and a centralized theme object

## Rationale
•	full control over aesthetic
•	avoids material UI look
•	easy to maintain consistent typography and colour palette


## Consequences
•	more manual styling work
•	must maintain consistency between screens
